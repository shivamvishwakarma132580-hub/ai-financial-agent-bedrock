AI Financial Research Agent (AWS Bedrock + Claude)

Overview

This project demonstrates an AI-powered agent built using AWS Bedrock and Claude Sonnet. The agent automates financial research workflows including data retrieval, analysis, and report generation.

Features

- Multi-step agent workflow
- Financial data comparison (e.g., Apple vs Microsoft)
- Automated report generation (PDF output)
- Tool integration (Web Search, Data Analysis)
- Structured logging for each execution step

Tech Stack

- AWS Bedrock
- Claude Sonnet
- Python
- Agent-based workflow architecture

Workflow

1. User query input
2. Query understanding
3. Financial data retrieval
4. Data analysis
5. Report generation
6. Output saved

Sample Output

A financial comparison report is generated and saved automatically.

Logs

The system maintains detailed execution logs including timestamps, tool usage, and success states.

Use Case

This project showcases how AI agents can automate complex research tasks using LLMs and external tools.

Future Improvements

- Real-time stock API integration
- Dashboard UI
- Multi-agent collaboration
